# Demo Wall 站点升级路线图 v1.0

> 创建时间：2026-10-25  
> 状态：规划中  
> 约束：**不新增外部 SaaS**（不接入 Turnstile、邮件服务商、Elasticsearch 等）；仅使用现有 Next.js、PostgreSQL、自建逻辑与部署环境能力。

---

## 一、文档目的

汇总产品在**安全、风控、用户交互、运营能力、性能与工程化**等层面的可升级项，供排期与评审。条目基于当前代码库现状整理，随实现进展应更新本文「已完成」与「待办」状态。

## 二、近期已完成（控制台与风控运营，2026-10）

以下能力已在开发中落地或合入，作为后续迭代的基线：

| 模块 | 能力 |
|------|------|
| 作品管理 | 日期/城市筛选；点赞列表分页；点赞人主页链接；点赞新号占比异常标识 |
| 用户管理 | 封禁状态筛选；注册日期范围；最近登录 IP；跳转认证日志 |
| 登录注册日志 | 可疑 IP 统计 Tab；按 IP/用户筛选；批量封禁；用户主页链接 |
| 操作日志 | 模块/动作中文映射（含盲盒等）；筛选下拉受控修复 |
| 通用 | 提交日筛选时区（UTC+8 自然日）`created-at-day-range` |

**仍待应用层落地（曾讨论、未做）**：注册 IP 限流、新号点赞冷却、人机验证、邮箱验证等——见下文「安全与风控」。

## 三、安全与风控（建议优先）

| 优先级 | 项 | 现状 / 风险 | 建议（无外部服务） |
|--------|-----|-------------|-------------------|
| P0 | 中间件语言漏网 | `middleware` 仅匹配 `zh-CN\|en-US` 的 submit/console/profile，`ja-JP` 可能未强制登录 | 使用 `routing.locales` 生成保护路径，或正则包含全部 locale |
| P0 | 注册无 IP 限流 | `/api/auth/register` 仅域名黑名单 + 写认证日志 | 查 `sys_auth_log`：`sign_up` + IP + 时间窗计数，超限拒绝 |
| P0 | 点赞无门槛 | 登录即可点赞，无频率与新号限制 | 新号冷却（如 24–72h）、每日点赞上限；写接口校验 `isUserBanned` |
| P1 | API 鉴权一致性 | 依赖各路由自行 `getAuthUser` / `isAdmin` | 敏感写操作清单 + 定期抽查；统一错误码与 401/403 |
| P1 | 密码策略 | 最小长度为主 | 弱口令本地词表拒绝；登录失败次数与临时锁定（IP 或账号） |
| P1 | 封禁覆盖面 | 登录与 JWT 已拦截封禁用户 | 点赞、投稿、改资料、上传等写接口显式封禁检查 |
| P2 | 上传与富文本 | 有部分限制 | 扩展名/MIME 白名单、图片尺寸上限；富文本消毒与展示一致 |
| P2 | 客户端 IP | 依赖 `X-Forwarded-For` 等 | 部署文档约定仅信任反代；管理端标注 IP 可信度 |
| P2 | 高危管理操作 | 已有操作日志 | 批量封禁等二次确认；日志 payload 增加可读「原因」字段 |
| P2 | Session | JWT + 封禁清空 token | 可选缩短 session；敏感操作前再查库 |

### 刷赞 / 批量注册（策略备忘）

- **成本**：无邮箱验证时，依赖 IP 限流 + 新号限制 + 运营工具（可疑 IP、批量封禁）组合。
- **数据**：`blocked_email_domains` 字典维护临时邮箱域名；`banned_users` 字典或后续迁表。
- **展示**：排行榜可对异常赞降权或后台重算 `likeCount`（定时任务或管理员触发）。

## 四、用户交互与产品体验

以下为可排期的**具体工作项**（含涉及页面/组件与验收标准）。与第五节「功能与运营」区分：本节侧重**界面、流程、反馈、一致性**，不新增业务能力表结构。

### 4.1 控制台筛选与布局统一

| 做什么 | 涉及位置 | 验收标准 |
|--------|----------|----------|
| 抽 `ConsoleFilterShell`（或扩展现有 `CrudFilterBar`） | `crud-filter-bar.tsx`；`console/users`、`works-management`、`posters-management`、`auth-logs`、`operation-logs` | 搜索框 + 主筛选 + `extraFilters`（日期、下拉）视觉一致；移动端同一套折叠/换行规则 |
| 重置行为一致 | 各控制台列表页 | 一键清空：搜索、日期、模块/角色/封禁等；页码回到 1 |
| 筛选激活态可见 | 用户管理、作品管理等 | 有未保存筛选时显示「已筛选」徽章或重置按钮（作品首页 `CityFilter` 已有类似模式可对齐） |
| 日期筛选文案 | 用户注册起止、作品日期、日志日期 | 占位符统一（「开始日期」「结束日期」或单日「日期」），时区行为与 `created-at-day-range` 文档一致 |

### 4.2 空态、加载与错误反馈

| 做什么 | 涉及位置 | 验收标准 |
|--------|----------|----------|
| 列表 Skeleton | 首页作品墙、`work-card` 网格、控制台列表 | 首屏加载显示骨架屏，替代仅全屏 `LoadingOverlay` 遮罩（可保留提交/保存时的 overlay） |
| 空态带行动点 | 首页无结果、个人中心无作品、`profile`、控制台「暂无 xxx」 | 文案 + 按钮：如「去投稿」「调整筛选」「去登录」 |
| 统一 Toast / `CrudFeedback` | 全站写操作 | 成功/失败文案简短一致；网络错误有「请稍后重试」 |
| 错误边界 | `app/[language]/error.tsx`（若无则新增） | 页面级崩溃友好页，可返回首页 |

### 4.3 表单与投稿流程（C 端核心）

| 做什么 | 涉及位置 | 验收标准 |
|--------|----------|----------|
| 步骤指示与校验时机 | `submit/page.tsx`、`StepIndicator`、`submission-form.tsx` | 切换步骤时校验当前步；错误汇总在步骤顶或字段下；未完成步骤不可提交 |
| 离开确认 | 投稿多步表单 | 有未保存内容时 `beforeunload` 或路由离开确认（可选） |
| 上传进度与失败 | `Step2VisualAssets`、封面上传、`/api/file` | 单文件进度/失败可重试；超 5MB 等错误用 i18n 文案（已有 key 可复用） |
| 海报快捷表单 | 海报制作相关页 | 与投稿一致的字段错误展示与提交中禁用按钮 |

### 4.4 点赞、收藏与登录引导

| 做什么 | 涉及位置 | 验收标准 |
|--------|----------|----------|
| 未登录点赞 | `work-detail-view`、`work-card`、点赞 API `LOGIN_REQUIRED` | 点击点赞跳转登录或弹窗，callbackUrl 回到当前作品 |
| 乐观更新与回滚 | 点赞 POST 成功前 UI | 先切换心形/数字，失败则还原并 toast |
| 重复点击防抖 | 点赞按钮 | 请求进行中禁用，避免连点双发 |
| 自己的作品 | 详情页 | 是否禁止自赞或隐藏按钮（产品定一条规则并实现） |

### 4.5 导航、返回与深链

| 做什么 | 涉及位置 | 验收标准 |
|--------|----------|----------|
| `from` 参数规范 | `user-profile-view`、`work-detail-view`、控制台链到用户页 | 有 `from` 则回跳；无则 `router.back()`（用户主页已实现，全站抽查补齐） |
| 控制台 → 用户/作品 | 用户管理、认证日志、点赞列表 | 已部分实现；补全海报管理、操作日志操作人链接等待办项 |
| 语言前缀 | `Link` from `@/lib/language/navigation` | 控制台内链不丢 `zh-CN/en-US/ja-JP` |
| 中间件与 locale | `middleware.ts` | 与 4.5 体验相关：`ja-JP` 下 submit/console 登录跳转正确（见安全节，但直接影响「被踢去登录」体验） |

### 4.6 首页、排行榜与筛选（访客侧）

| 做什么 | 涉及位置 | 验收标准 |
|--------|----------|----------|
| 筛选与作品管理一致 | 首页 `CityFilter`、`page.tsx` | Pill 交互、重置、移动端折叠与控制台/作品墙一致（已部分统一，查漏补缺） |
| 分页与加载更多 | 首页列表 | 翻页/加载时保留筛选条件；加载态不闪屏 |
| 排行榜说明 | `rankings/page.tsx` | 排序规则简短说明（按点赞/时间等）；若后台降权异常赞，前台可加脚注（依赖运营策略） |
| 盲盒 FAB | `code-blind-box-entry` | 首次显示 `fabDragHint` 气泡一次；短屏仅缩放吉祥物（已实现可文档化） |

### 4.7 无障碍与可读性

| 做什么 | 涉及位置 | 验收标准 |
|--------|----------|----------|
| 图标按钮 | 控制台 `Button size="icon"`、作品卡片操作列 | 每个仅有图标的按钮有 `title` 或 `aria-label` |
| 键盘 | 弹窗 `Dialog`、日期 `DatePicker` | Esc 关闭；焦点陷阱基本可用 |
| 对比度 | 控制台 muted 文案、黄/红警告条 | 抽查 WCAG AA；点赞异常、新号警告条可读 |

### 4.8 多语言（体验向，非全文翻译）

| 做什么 | 涉及位置 | 验收标准 |
|--------|----------|----------|
| 控制台文案入词典 | `console/**` 硬编码中文 | 优先：`layout` 导航、通用按钮（保存/取消/重置）、空态 |
| 与 C 端一致 | `en-US` / `ja-JP` 访问 `/en-US/console` | 导航与筛选至少可读；日期/数字格式随 locale |
| 认证/操作日志 | 行为类型已中文映射 | 英文界面下 module/action 显示 i18n 而非仅中文表 |

### 4.9 建议实施顺序（体验包 C 拆分）

1. **4.5 导航 + 4.2 空态行动点**（改动小、体感明显）  
2. **4.1 控制台筛选统一**  
3. **4.3 投稿步骤校验 + 4.4 点赞引导**  
4. **4.6 首页/排行榜 + 4.8 控制台 i18n 骨架**  
5. **4.7 无障碍**（可穿插在前述项中顺手补）

## 五、功能与运营（无外部服务）

| 项 | 建议 |
|----|------|
| 风控配置入口 | 字典页说明 `blocked_email_domains` / `banned_users`，或独立「风控配置」卡片 |
| 日志导出 | 认证日志、操作日志、作品点赞 CSV（API 或前端生成） |
| 站内通知 | 审核通过/驳回：站内消息表 + 个人中心红点（不接邮件） |
| 审核待办 | 控制台概览展示待审作品/海报数量 |
| 数据修复 | 管理员触发重算点赞数、剔除已封禁用户赞 |
| 搜索增强 | PostgreSQL `pg_trgm` 索引优化用户/作品搜索（仍不用 ES） |
| 盲盒活动期 | env 或字典配置起止时间（已有 feature flag 可扩展） |

## 六、性能与可靠性

| 项 | 建议 |
|----|------|
| 查询聚合 | 列表页避免 N+1；批量查登录 IP、likeRisk 等模式推广 |
| 缓存 | 字典、封禁名单、首页 filter-options 短 TTL 内存缓存 |
| 图片 | `next/image`、统一封面尺寸、懒加载 |
| 健康检查 | `GET /api/health`（DB ping）供部署与监控 |
| 日志 | 生产关闭冗长 `prisma:query`；统一错误边界页 |

## 八、推荐实施包（便于排期）

### 包 A：安全补丁（P0，约 1–2 迭代）

1. 修复 `ja-JP`（及全部 locale）中间件保护路径  
2. 注册 IP 限流（基于 `sys_auth_log`）  
3. 新号点赞冷却 + 每日点赞上限

### 包 B：运营效率

1. 字典/风控配置说明与维护引导  
2. 认证/操作日志导出  
3. 控制台概览待审数字  

### 包 C：体验统一

1. 控制台筛选组件化  
2. 空态 / 加载态规范  
3. 控制台 i18n 骨架（en/ja 关键页）
