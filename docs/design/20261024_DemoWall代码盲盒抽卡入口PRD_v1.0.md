# Demo Wall 首页「1024 代码盲盒」抽卡入口 PRD

# 需求背景

10 月 24 日，TRAE 将在全国多个城市同时举办「TRAE Friends 1024 程序员节」线下活动，核心玩法为「代码盲盒」：参与者从主题词、功能词、风格词三个词库中各随机抽一张卡，三张词组合成命题，队伍在 90 分钟内用 TRAE 现场做出 Demo，最后在 Demo Wall 上提交并投票。

**抽卡方式：**参与者在自己电脑上打开 Demo Wall 首页，通过右下角的 TRAE 宝悬浮形象进入抽卡弹窗完成抽卡。抽卡结果与账号绑定，同一用户只能抽一次。



# 功能一：右下角悬浮入口（TRAE 宝形象）/页面中增加 Tab

## 入口形态

|项目|要求|
|---|---|
|**位置**|页面右下角固定悬浮，不随页面滚动消失；悬浮层级为页面最高（不被任何内容遮挡）|
|**形象**|TRAE 宝品牌 IP 动画形象；形象尺寸约 80\-100px 高|
|**引导气泡**|小人左侧（或上方）弹出一个对话气泡，白底圆角，黑色文字：**「点击抽取 1024 代码盲盒！」**，气泡带小尾巴指向小人，3\-5 秒后可自动淡出，hover 小人时再次浮现|
|**点击行为**|点击小人任意位置 → 打开抽卡弹窗（见功能二）|

## 入口状态

|状态|气泡|点击行为|

# 功能二：抽卡弹窗

## 交互流程

1. 用户点击右下角 TRAE 宝，弹出居中 Modal 弹窗，遮罩压暗背景

2. 弹窗标题：「1024 代码盲盒」；副标题：「抽取三张关键词，定义你的 90 分钟命题」

3. 弹窗内并排展示三张卡片（A 主题词 / B 功能词 / C 风格词），初始为背面，背面分别标注「A 主题词盒」「B 功能词盒」「C 风格词盒」

4. 用户逐张点击卡片，卡片 3D 翻转揭开结果（翻牌动效约 0\.5s，三张可连续点击）。**翻开第一张卡的瞬间，系统即把这组三个词写入后端并与账号绑定（后续关闭弹窗、刷新页面都不会改变这组词）**

5. 三张全部翻开后，弹窗底部展示组合命题句：**用「C 风格词」的方式，做一个关于「A 主题词」的「B 功能词」**

6. 底部按钮：「就是它了」——作用仅为收起弹窗（结果在翻开第一张卡时已落库，此处不再承担提交动作）

## 交互规则

- **一人一次（关键防刷规则）：**用户打开弹窗、看到三张背面卡时，可随时关闭弹窗，**不算抽过**（避免误点小人就作废一次机会）；**一旦点击第一张卡开始翻牌，系统立即把本次随机结果落库绑定 user\_id**——此后无论刷新页面、关闭重开、断网重进，再打开弹窗都展示同一组结果，不可重抽

- **随机规则：**从完整词库中独立随机抽取，A/B/C 三个维度独立随机，不做去重约束

- **不允许重抽：**弹窗内不提供重新抽卡的按钮；现场如需调整关键词，走线下「换词时间」环节，不通过线上

- **遮罩点击：**未翻牌前（看到三张背面卡）点击遮罩或关闭按钮可正常关闭弹窗，不算消耗抽卡机会；**一旦翻开任意一张卡，遮罩点击不再关闭弹窗**，必须走底部「就是它了」按钮收起（此时结果已锁定，关闭后再进来仍是这组）
