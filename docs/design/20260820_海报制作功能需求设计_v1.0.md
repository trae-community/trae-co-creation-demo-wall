# 海报制作功能需求设计 v1.0

> 创建时间：2026-03-31  
> 状态：待开发

---

## 一、功能概述

新增「海报制作」功能，用户通过快捷表单（昵称、描述、上传图片、作品 Demo URL）快速生成分享海报。海报纯前端生成，同时入库保存，拥有独立的海报展示区和管理后台。

### 核心特点

- **快捷入口**：省去完整提交流程，只需 4 个字段即可生成海报
- **实时预览**：左侧填写表单，右侧实时预览海报效果
- **独立体系**：与现有作品提交完全独立，单独管理
- **共享账号模式**：可预登录「DemoWall 大赛官号」，用户输入昵称即可区分作者

---

## 二、数据模型

### 新建表：`work_posters`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | Int | 主键，自增 |
| `userId` | String | 创建者 ID（当前登录账号） |
| `nickname` | String | 海报上显示的昵称 |
| `description` | String | 作品描述 |
| `imageUrl` | String | 上传的作品图片（COS） |
| `demoUrl` | String | 作品 Demo 地址（用于生成二维码） |
| `auditStatus` | Int | 审核状态：0=待审核，1=已通过，2=已拒绝 |
| `tags` | Json? | 标签（如含免审核标签则跳过审核） |
| `createdAt` | DateTime | 创建时间 |
| `updatedAt` | DateTime | 更新时间 |

> 表名遵循现有 `work_` 前缀命名规范。

## 三、页面规划

### 3.1 海报制作页

- **路由**：`/[language]/poster-maker`
- **布局**：左右两栏（移动端上下堆叠）
  - **左侧表单**：
    - 昵称（必填）
    - 描述（必填）
    - 上传图片（必填，走现有 COS 上传）
    - 作品 Demo URL（必填）
    - 提交按钮
  - **右侧预览**：
    - 实时渲染海报效果（与现有海报模板一致）
    - Demo URL 自动生成二维码嵌入海报右下角
    - 可下载海报图片

### 3.2 海报展示区（列表页）

- **路由**：`/[language]/posters`
- **公开访问**，无需登录
- 展示已通过审核的海报列表
- 卡片样式展示，点击进入详情

### 3.3 海报详情页

- **路由**：`/[language]/posters/[id]`
- 展示海报大图、作者昵称、描述、Demo 二维码
- 可下载海报

### 3.4 海报管理页（Admin）

- **路由**：`/[language]/console/posters`
- 仅管理员可见
- 功能：查看所有海报、删除、审核操作

## 四、API 设计

| 方法 | 路由 | 说明 |
|------|------|------|
| `GET` | `/api/posters` | 获取海报列表（支持分页、审核状态筛选） |
| `GET` | `/api/posters/[id]` | 获取单个海报详情 |
| `POST` | `/api/posters` | 创建海报（上传图片 + 表单数据） |
| `DELETE` | `/api/posters/[id]` | 删除海报（管理员） |
| `PATCH` | `/api/posters/[id]` | 更新审核状态（管理员） |

---

## 五、审核流程

1. 用户提交海报表单 → 创建记录（`auditStatus = 0`）
2. 检查用户标签：
   - 含「免审核」标签 → 直接设为 `auditStatus = 1`
   - 否则 → 进入待审核队列
3. 管理员在 `/console/posters` 审核/删除

## 六、首页改造

首页新增「海报展示窗」，与现有作品展示可切换：

```
┌─────────────────────────────────┐
│  [作品展示]  [海报展示]          │  ← Tab 切换
├─────────────────────────────────┤
│                                 │
│   展示区域（作品 / 海报）        │
│                                 │
└─────────────────────────────────┘
```

- 默认展示作品（保持现有行为）
- 切换到海报时展示已通过审核的海报（取最新若干条）
- 点击「查看更多」跳转到 `/posters`
